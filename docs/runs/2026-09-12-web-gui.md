## 启动修正与限制

Nix 环境原先位于项目根目录，`path:.` 会尝试复制约 40 GiB 的模型目录。现在将 flake 和其锁文件移到独立的 `nix/`（约 12 KiB），只提供 `path:./nix` 入口；已验证启动及规划器、Java、l2d 的路径。网页模块不参与模型阶段的代码指纹，单独修改界面不要求重跑生成阶段。

页面预览是流水线已有的图像与 CPU 姿态渲染结果，不是实时 Live2D 播放器。官方 Core / 目标应用兼容性仍未验证。失败阶段重试仍采用原有阶段级缓存，不承诺只重跑阶段内部的最后一个操作。

后续仓库整理：权重已迁移至主 HF 缓存，项目仅保留软链接。建立 Git 仓库后，flake 与锁文件移回根目录；当前使用 `nix develop` 的 Git 输入过滤，`.gitignore` 排除模型、运行环境和产物。上文独立 `nix/` 方案已移除。
