# 2026-10-23 Skill 制作质量流程改进

目标：把实际制作暴露的问题转为后续角色可复用的流程和验收标准，而不是只修补 Mio。修改 skill 入口及组件、参数、详细制作、表演、验收、工具参考；新增 facial-production.md 和 runtime-validation.md。安装路径 ~/.codex/skills/live2d-production 已链接到仓库目录，无需重新安装。

## 决策变化

- 现有模型先检查真实导出，新角色检查首个可用导出；最后再检查最终模型和轨迹。Core、视觉、SDK 物理、目标应用分开报告。
- 从环境变量、项目配置、用户给定包定位 Core；有限范围未找到不能断言未安装。路径不硬编码到 skill。
- 精细关键形前规划相关部位拆层、遮挡补画和父子结构；按区域完成增量，保留无关区域，不强制一次重做所有部件。
- 对会说话的角色，优先口型、眼形情绪、眉曲率和转头深度；用中间姿态与组合画面验证，而非控制数量。
- 表情只写需要的通道，记录驱动归属、覆盖和释放；不可分辨的情绪标为 weak，不能用无破面检查代替识别度。
- 多节物理需要对应分段网格或局部变形层级；参数用可读语义，已有散列 ID 保留映射，不假设底层支持直接重命名。
- 保留默认 agent 内置生图、仅明确要求全本地时使用本地 AI 的政策，以及不可变版本/用户验收边界。
