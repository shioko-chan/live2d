## 使用的现有能力

Qwen3.5-9B Q4_K_M 与 F16 mmproj 通过本地 llama.cpp 运行；权重固定版本下载至主 HF 缓存，项目仅保存软链接。原有 Qwen3-4B 文字规划器继续用于普通修改。

SAM2 负责局部选择；anime LaMa 补全原上衣中被领结遮住的区域；PSD2Live 的 MCP `warp_create`、`parameter_create`、`keyform_set`、`rig_transform` 和 `physics_put` 负责绑定，没有实现另一个绑定引擎。

## 实测中发现并修正的问题

1. VLM 混淆源图层像素坐标和整图位置。改为先选择部件，再单图输出 0–1000 坐标，由程序转换。
2. 单个前景点可能落入飘带间空隙。SAM2 在有限的五个点上生成候选，填充内部小孔；掩膜按 IoU 去重，避免六张近似错误结果挤掉正确候选。
3. SAM 最高置信度掩膜会包含衣领。让 VLM 比较放大后的不同候选，而不是把分割置信度当成物件身份判断。
4. 低密度的父坐标系网格让领结根部轻微漂移。改为 32×32 的独立子网格与 30% 根部固定区域；3°样例的连接点附近 360 像素窗口，在两个摆动端点均无超过 8/255 的通道变化。这个检查只针对该窗口，不能证明所有顶点或动作组合都正确。
5. VLM 会对脸部裁剪图中看不见的领结给意见。记录每张图的裁剪范围与可见部件，过滤越界判断；自动减幅还必须有该部件独立摆动端点的证据。

## 检查与限制

64 个自动测试通过，Ruff 和 `git diff --check` 通过。实际运行了下载、本地视觉推理、SAM2、LaMa、PSD2Live 构建、渲染、视觉复查和一次保守修正。浏览器检查确认 40 张预览、新按钮和报告显示正常。

VLM 仍有误报：例如把原有衣服阴影理解为缝隙、把静态图片描述成已经检查过物理响应。报告明确是待复核建议，保留原始回复和被过滤意见；程序不因此自动移动根部、重绘角色或接受版本。当前自动修正仅限高置信度的独立摆幅错误，最多一次，然后交给用户验收。

没有验证任意发束细分、跨坐标系换父级、多段物理链、自动换装或官方 Core/目标 VTuber 应用。新增部件的隐藏补画与审美质量仍需要看动作预览。此增量提供可运行的部件细化与检查入口，并不等于全角色自动精修已经稳定解决。
