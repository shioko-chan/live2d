## 实证结果

原故障是静态闭嘴纹理没有 MouthForm 几何，而生成唇线/口腔随 Form 改宽度和曲率。
144 张分层诊断图与实际代码一致：旧平移只能改位置，不能改曲线对应。

唯一结构候选 **03e76af8caa54714** 从 f83489945b5448c1 出发，使用共同曲线和
共享 warp，保持原透明度。原实现者保存 130 个姿态、30 组隔离轮廓和 17 帧有序扫描。
监督方又在临时副本独立渲染 34 张图、读取实际顶点，并查看全图、口部和单眼组合。

| 检查 | 结果 |
| --- | --- |
| 同一 v1 shared-u 度量的旧失败 → 新候选 | 7.1241 → 1.1695 px，宽比 1.35664 → 1.0625 |
| 冻结的距离 ≤1 px、宽差 ≤10% | 1/30 通过；仍失败，没有事后放宽 |
| 中性、眨眼、半闭眼、左右单眼和小幅转头保持 | 实际 RGBA 一致 |
| 全开口严格 RGBA 保持 | 14/15 组合有 3–15 个像素改变 1 灰阶；严格条件失败，未观察到明显外观退化 |
| 共享 warp 与预定解析场的实际顶点差 | 中性最大 0.62533 px；原失败姿态 0.66442 px，证明存在表示误差 |

上述 7.1241 是包含端点的同 u 二维距离，不能与早期“同 x 内部纵向差 3.2435”混算。
旧失败对照来自 1bf0686147f84cca；端点保持使用新鲜的直接父版本 f834 对照。

另发现测量器把均匀深色笔画的首个最强像素误当中心。相同 y=20 的控制线，仅笔画
厚度不同即可偏移 0.25–1.25 px。已修复为完整峰平台中心，所有六组控制回到 y=20，
保留 v1 复现函数。v2 对同一候选的诊断仍只有 7/30 达到相同数值要求，最大仍为
1.29980 px；**没有将候选追认为合格**。原 v1 判定及所有图片未改。
