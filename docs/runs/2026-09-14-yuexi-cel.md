## 过程与修正

- 使用已确认的 API 立绘作为源图，未重新生成人物。规划器最初引用不存在的绑定对象，改为明确的无额外操作计划，使用现有默认动作绑定。
- See-through 分别处理身体、脸部和深度。上衣图层错误包含灰白背景；人工检查后，以现有 SAM2 在 CPU 上重新分割上衣，置信度 0.946，保留原始颜色及 alpha，裁剪至实际部件边界。原始拆层结果保留。
- 自动补画独立张嘴口型使用本地 Qwen Image Edit，耗时 23 分 46 秒；SAM2 自动提取成功，置信度 0.869。本次未手动定位口型。
- 将清理后的素材导出为分层 PSD，创建新版本完成绑定，避免重新运行昂贵的拆层和补画。

## 验证与限制

模型包结构检查通过，检查了默认、左右转头、双眼闭合及张嘴的实际 CPU 渲染样例。预览来自 72 帧模型参数渲染，GIF 合并相邻重复帧后为 62 帧，时长 6 秒，共 42 个不同画面，依次展示转头、眨眼和张嘴。没有做物理时间仿真。
