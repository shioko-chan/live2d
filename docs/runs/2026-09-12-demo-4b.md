# 当前管线生成模型的实测

用户请求运行现有管线生成一个模型。采用银发、蓝眼、白色外套的成年女性角色，正面半身、睁眼、闭嘴微笑。

## 结果

- 工程：`projects/demo-4b-20260912`。
- 初始生成版本：`6a51cd632f514090`，保留原画、拆层、补画和失败记录。
- 修复后完成版本：`022a0050f386458d`，状态 `built`，用户接受标记为空。
- 交付：`deliveries/demo-4b-20260912` 和同名 ZIP，包含模型包、PSD、PSD2Live 工作区、原画、动作预览及证据。
- 预览：8 秒、12 fps、96 帧、768×768，按顺序展示转头、双眼闭合/单眼眨眼、张嘴、组合动作。每帧通过 PSD2Live 的 CPU `view_render_model` 实际计算，没有图片淡化。源工作区哈希和 MCP 历史保持不变。

## 实际执行与修复

1. Qwen3-4B-Instruct-2507 第一次规划遗漏表情标签；把 `open eyes, closed mouth, smile` 明确写入需求后重新规划，保留原始计划。没有手改生成图片。
2. ComfyUI + Animagine 生成原画，任务日志耗时 29.05 秒。背景左上略带灰色，拆层后的透明合成正常，没有多出翅膀等部件。
3. 初次拆层被中断（143）；恢复时复用已校验原画。See-through 的身体/脸部各 30 步、深度 4 步推理分别约 121/103/8 秒，另外还有加载和图层整理时间。共得到 20 个有效图层。
4. 管线检测缺少 `mouth_open`，4B 模型自动给出 add 计划，复用闭嘴层的位置 `[496,210,41,17]`。Qwen Image Edit 补画 28 步，完整任务耗时 **23 分 24 秒**，其中去噪约 21 分 58 秒。
5. SAM2 找到了形状正确的嘴部，但候选框 `[70,85,185,165]` 比提示框 `[64,89.6,192,166.4]` 向上超出约 5 像素，被严格边界判断拒绝。修正为允许提示框宽高各 10% 的边界偏差，继续保留置信度、中心连通域和范围检查。新增回归验证正常嘴唇轻微越界可通过，整脸、明显越界、低分和 NaN 仍拒绝。
6. 在独立恢复目录中复用补画，只重新运行 SAM2；最佳候选分数 0.916。加入嘴部后有 21 层，素材检查通过。由于现有恢复粒度是整个素材阶段，为避免重算昂贵补画，将恢复后的 PSD 作为新版本输入，使用现有管线完成绑定与导出。原失败记录保留。

## 质量与验证

模型包结构检查通过。静态样例和连续帧能展示眼睛闭合、张嘴、左右转头（参数端点 ±45）；动作段的独立画面数量分别为 13、13、7、13。CPU 动画渲染及编码约 18 秒，GIF 时间轴另按 10 ms 精度编码并验证为 8000 ms。43 项回归测试及 Ruff 通过。

基础预览可用；发丝边缘和大角度转头仍有自动拆层/绑定的粗糙之处，未做人工精修。动画未进行物理时间仿真，官方 Cubism Core 和目标应用兼容性仍未验证。

225 个整机采样观察到显存峰值 17,380 MiB、最低主机可用内存约 4.57 GiB；采样包含其他程序和被中断的首次尝试，不应解释为本模型独占峰值。生成与预览完成后，本管线的模型容器、语言模型服务和采样进程均退出。

本轮没有达到完全无人介入：需要明确一次表情要求，并修复一次掩膜边界检查。当前主要耗时在口型图像编辑，较小的规划模型没有改变该阶段的计算量。
