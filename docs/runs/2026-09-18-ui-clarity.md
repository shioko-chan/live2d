# UI 操作范围与版本状态修复

修复 8 项交互歧义：

1. 原稿、参考图互斥；已有模型的普通修改禁用参考图。后台拒绝不生效的输入组合。替换未完成方案时可明确取消沿用旧图片。
2. 提交前选择外观修改、部件细化或只检查；各自使用对应按钮、说明和输入范围。
3. 执行已有方案有独立阶段选择；只展示尚未完成且适用的阶段，不读取未提交的需求框。
4. 方案展示细化操作、部件名、原因、摆幅前后变化及执行状态。
5. 人工验收和切换创作起点分开；CLI 同步改为独立 `l2d accept`。
6. 构建、视觉检查、人工验收和运行兼容性分别显示；任务、下载按当前查看版本匹配。
7. 检查意见使用中文级别和部件名，按钮定位实际姿态图；已执行细化与仍待核对的意见分别显示。
8. 动作视频独立标签页；静态大图与缩略图相邻，切换到图片时暂停隐藏视频。

验证：

- 73 项 Python 测试通过；新增输入冲突、历史版本验收、分阶段执行、姿态关联及细化前后数据测试。
- Ruff、JavaScript 语法和 git diff 空白检查通过。
- 实际浏览器验证：月汐视频标签隐藏静态图；只检查模式可留空、隐藏上传与执行阶段；细化模式显示完整执行范围。
- 点击“查看：身体左右 -10”切换到 `pose-07.png`，退出视频区域。
- 切换历史版本 `bb5ee1ce` 时，不显示 `220b24ef` 的任务和下载；验收按钮仍可用，但不会切换创作起点（后台测试验证）。
- 暂停版本显示素材、模型两种继续阶段；改变继续阶段不会改动新方案的目标阶段。
- 修复测试中发现的静态资源缓存混用：页面按脚本及样式的内容摘要引用资源，响应要求重新验证缓存。
