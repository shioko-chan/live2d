## 结论：应先核对 0 附近的闭合几何，不要再缩窄阈值

是的，应优先核对两套口型在 Open≈0 时的几何闭合位置。如果两条线的空间位置不同，透明度交叉淡化无论多窄，过渡窗口内都必然出现双线。缩窄阈值只会把问题挤到更小的区间，并让切换更像"跳位"。

## 最少的只读消融与测量

**采样点**：Open = 0 / .02 / .05 / .1，Form = −1 / 0 / 1，转头 = 0 / 14。

**三组单层渲染**（其余层隐藏，仅用于测量）：
1. 只显示静态 MouthClose。比较它在 0 与 .05 时的线位置。如果线移动了，说明静态层自身被 Open 关键形变带动，属于静态 mesh 或贴图错位。
2. 只显示自动 lip_0/lip_1，并临时强制不透明。测量 Open=0 时上下唇是否重合成单线，以及这条线与静态线的距离。如果不重合或有偏移，就是自动 lip 位置错位。
3. 只显示 open cavity。如果 .05 时深线在嘴唇隐藏后仍然存在，说明深线来自 cavity 的上缘，或者 cavity 未收拢成零高度。

**测量方法**：在嘴中心和左右两侧共三列，取纵向亮度剖面，记录暗线峰值的 y 值，列成偏移表（像素）。另外可只读导出模型中 Open=0 的关键形顶点，作为交叉印证。

## 下一次修复的设计

- **统一闭合线**：以静态闭嘴线（或者反过来，以自动轮廓）为唯一闭合中线，把自动 lip 的 Open=0 关键形吸附到这条中线上，并在每个 Form/转头组合下逐一对齐。
- **几何连续开口**：上下唇从同一中线连续分离；cavity 在 0 时高度为 0，随 Open 增大而长高，不靠透明度"出现"。
- **只在几何重合时淡化**：确认两层偏差 ≤1px 后再做短交叉淡化。更好的做法是让自动层在 0 时直接承担闭嘴线，静态层只保留填色或干脆移除。
- **验收标准**：在 0 到 .25 密采样，每帧暗线数量为 1，且 y 值单调连续、无跳变。
