# 花守铃乃 · 新角色制作

用户要求不沿用旧角色，由助手决定人物设定，创作日本插画风格的 Live2D 角色。角色为 25 岁的夜间植物标本店店主，栗棕长发、翡翠眼睛、奶油白蕾丝衬衣、墨绿植物刺绣背心和棕色百褶裙。配有山茶花发饰、琥珀耳坠、胸针领结、腰链钥匙。

项目：`projects/suzuno-20260918`；完成候选：`d2e1d5bacf5f485c`，built，未标记用户接受。原画和完整提示词在 `artwork/`。本轮未修改共享管线实现或默认生图模型。

## 原画与素材

- 默认本地生图仍是 Animagine XL 4.0、832×1216、28 步。已有输出未能证明它能稳定达到用户期望的细密配饰设计；本轮采用此前授权的 API 生图方式。
- 原画使用内置 image_gen 生成，1024×1536；张嘴口型也由 image_gen 按同一角色画风生成。这些输出不能作为本地 Animagine 品质的证据。
- See-through 生成 1024×1024 画布素材。其输出保留主要刺绣、发饰、耳坠、胸针领结和腰链，但会重绘局部并损失部分原画分辨率。
- 完整拆层保存在 `b08a6a24372c446b`。因改用 API 口型，主动停止了本轮原定的慢速 Qwen 口型补画；这个中间版本保留失败/中止记录。SAM2 提取 API 口型的候选得分为 0.7899；左右耳坠沿透明间隔分离，整理后的 25 层默认合成逐像素一致。
- 自动配饰细化提出领结胸针拆分与左右耳坠绑定。一次任务在启动视觉核验时收到 SIGTERM，原因未确认；恢复时复用了已保存计划。
- SAM2 候选误包含白衬衣，VLM 曾以 0.95 置信度错误接受。助手检查发现后，以多点提示和针对这张图的颜色约束修正掩膜，补全胸针高光，保留两条完整飘带并排除中间衬衣。LaMa 补画遮挡区域；最终 26 层默认合成仍逐像素一致。
- 素材处理脚本、提示点、候选掩膜及检查图保存在项目 `artwork/`，本轮包含人工指导式修正，不是完全无人干预。
