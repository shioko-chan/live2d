# 验收

## 检查范围

用户已于 2026-09-12 授权实际 GPU 推理与模型下载。CPU 回归和静态检查仍作为基础检查；实际执行证据见 [运行记录](runs/2026-09-12.md)。

测试中的 MOC3 fixture 只检验文件结构检查器，不是真实模型；模拟服务结果不能证明格式兼容或图像质量。`runtime_verified` 默认始终为 false。

## 实际验收步骤

1. 准备固定源码、软件环境和模型。先检查磁盘；不要通过运行推理触发下载。
2. 使用规范半身 PSD 运行绑定，确认 `.moc3`、CMO3、纹理和 JSON 真实生成；查看 `pose-*.png` 的眨眼、口型、转头及转头加闭眼组合。
3. 使用一张 PNG 执行 See-through，检查部件数量、透明边缘和重组合成，再绑定。此步骤测定 FP16 数值稳定性，出现空白或 NaN 不能直接提高重试次数。
4. 从中文需求执行全链路，记录每阶段耗时、CPU 内存和显存峰值。当前不预设“多少秒完成”的承诺。
5. 分别做改色、固定轮廓重绘、新增饰品、删除饰品、绑定参数调整和整图重生成。检查未修改像素、父版本文件哈希、历史操作重放以及失败分支回退。
6. 中断 ComfyUI/拆图任务并恢复，确认不重复已经验证的前置步骤，且仅本任务进程停止。
7. 可选用自己获得的 Core 库运行 `l2d verify-runtime BUNDLE --core LIBRARY`，或将导出模型导入 VTube Studio。Core 检查只加载和计算默认姿态，不验证图像、遮罩和物理；最终仍需目标软件动态检查。
8. 确认结果后 `checkout REVISION --accept` 并 `export`，不要将临时候选误当已验收模型。

`built` 仅表示管线完成并通过结构检查；`accepted` 表示用户看过并接受该版本。官方运行验收不自动改变项目状态或声称全部功能兼容。
